Tool

Tool :: # (opaque)

A provider-native tool name, optionally qualified as "source#name". Generic syntax is checked here; explicit source grammar is checked during whole-project validation. Auto sources are interpreted by the chosen backend.

from_quote : Str -> Try(Tool, [BadQuotedBytes(Str)])
to_ir : Tool -> Tool
to_str : Tool -> Str

Made by people who like to make nice things.
