Std

:= []
kaifile : List(Setting) -> Kaifile

The usual Kaifile.roc: std alone.

plugin : List(Setting) -> Plugin

Invalid settings become the plugin's problems, so Kaifile.roc fails to compile.

checked_model : List(Setting) -> Try(Model, Str)

The settings' model, with Systems and Raw checked too so kai check reports what no backend accepts instead of every command failing later.

commands : Model -> List(Command)
step_text : WorkflowStep -> Str
request : Str, Args -> Try(Request, Str)

The model request a command's parsed arguments name.

implementations : Model -> List(Implementation)
fit_nix : Model, Request -> Try({}, Str)

Whether Nix can serve the requested closure, a workflow's tasks included; unrelated shells, tasks and builds never matter. Nix planning checks builds itself.

known : Model, Request -> Try({}, Failure)

A shell, task, build or workflow the project does not declare.

known_inputs : Model, List(Str) -> Try({}, Failure)

Inputs kai update was asked to move that the project does not declare.

plan_nix : Model, Request, Context -> Try(Plan, Failure)

Nix plans read the lock authority; its absence is a planning failure.

entered : Model, Request -> List(Str)

The environments a request's shells and tasks enter.

run_in : List(Setting), Context, Run -> Try(Plan, Failure)
revised : Model, Context -> Model

A build declaring Revision receives the project's revision in its environment, over its own Env.

nix_layout : Layout -> Layout

Nix's generated files live in their own directory beneath kai's generated root; Guix's beside them.

guix_pins : Model, Context -> Try(Locked, Failure)
guix_lock_failure : Str, Str -> Failure

A lock problem that updating the Guix pins fixes.

guix_failure : Str, Str -> Failure

Why a Guix plan failed: a source the lock has no hash for, or why.

guix_lockable : Model -> Try({}, Str)

Guix has something to lock when any environment can run on it.

update_guix : Model, Context -> Try(Plan, Str)

Phase 0 resolves the channels and hashes the path: sources with the installed guix repl and asks kai for the result; phase 1 validates it and publishes the lock's guix section, keeping the others.

lockable : Model -> Try({}, Str)

Nix has nothing to lock in a project using only Guix sources.

update_nix : Model, Context -> Try(Plan, Str)

Phase 0 resolves the inputs with Nix and asks kai for the result; phase 1 validates it and publishes the lock.

Run : { environment : Str, argv : List(Str), description : Str }

Made by people who like to make nice things.
