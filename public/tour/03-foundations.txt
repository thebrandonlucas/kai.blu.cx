  Setting up a project, the usual way

    1. read the README
    2. install Python 3.11 (not 3.12!)
    3. install Node 20, with nvm
    4. brew install postgresql@16
    5. run ./setup.sh, fix what it breaks

    7. it works on your machine... for now
